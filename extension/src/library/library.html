Outputs

  • Markdown (.md) — YAML front matter (source URL, author, dates, word count), an outline, the cleaned content, then tables of embedded videos, images and links. Upload it to Claude or a Claude Project as-is.
  • Study document (.docx) — cover page, overview, table of contents, learning objectives, the full content with images, key takeaways, key terms, video resources, review questions and space for notes. Opens in Word, Google Docs, LibreOffice and Pages.
  • Site kit (.zip) — offline copy of the page with local CSS/images/fonts/scripts, original snapshot, screenshot, design tokens (colors, typography, spacing, breakpoints, CSS variables), section and layout maps, asset manifest, all video links and a RECREATE.md guide with a ready-made prompt for Claude.

Embedded videos

Videos are detected from iframes, <video> tags, lazy-load placeholders (e.g. lite-youtube), Open Graph/Twitter tags and JSON-LD — YouTube, Vimeo, Loom, Wistia, Dailymotion, TikTok, Twitch, Bilibili, TED, Vidyard, Brightcove, Google Drive, direct video files and more. Every output lists both a watch URL and an embed URL.

Shortcuts

Alt+Shift+S collect page · Alt+Shift+K site kit. Change them at chrome://extensions/shortcuts.

Tips

  • To avoid a "Save as" prompt for every file, turn off Ask where to save each file in Chrome's download settings.
  • Use Export Claude bundle to hand Claude a whole research session at once: it includes an index.md catalog plus one file per page.
  • Everything stays on your computer; nothing is sent to any server.
